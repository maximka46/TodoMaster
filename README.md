📋 TodoMaster – To-Do с приоритетами и дедлайнами 
Мощный менеджер задач с поддержкой приоритетов, дедлайнов, фильтрации, сортировки, поиска и цветного интерфейса.
Управляйте своими задачами эффективно прямо из командной строки!
Реализован на 7 языках программирования с единым интерфейсом и хранением в JSON-файле.

🚀 Возможности
Управление задачами – добавление, удаление, отметка выполнения, редактирование.

Приоритеты – High, Medium, Low (цветная индикация).

Дедлайны – установка даты выполнения (YYYY-MM-DD).

Фильтрация – по статусу (pending/done), приоритету, дедлайну.

Сортировка – по приоритету, дедлайну, дате создания.

Поиск – по ключевым словам в заголовке и описании.

Экспорт/Импорт – сохранение и загрузка задач в JSON.

Статистика – количество задач, выполненных/невыполненных.

Цветной вывод – приоритеты и статусы выделены цветами.

Хранение – все данные сохраняются в JSON-файле в домашней папке.

📖 Использование
Синтаксис (единый для всех версий):

bash
<команда> <действие> [аргументы] [опции]
Действия
Команда	Описание
add "Заголовок" "Описание" -p High -d 2025-12-31	Добавить задачу
list [--filter status=done] [--sort priority]	Список задач
done <ID>	Отметить задачу как выполненную
delete <ID>	Удалить задачу
edit <ID> --title "Новый заголовок"	Редактировать задачу
search "ключевое слово"	Поиск по заголовку и описанию
stats	Показать статистику
export <файл.json>	Экспортировать задачи
import <файл.json>	Импортировать задачи
help	Справка
Примеры
bash
# Добавить задачу
todo add "Купить продукты" "Молоко, хлеб, яйца" -p High -d 2025-12-25

# Список всех задач с сортировкой по приоритету
todo list --sort priority

# Отметить задачу #3 как выполненную
todo done 3

# Поиск задач с "продукты"
todo search продукты
